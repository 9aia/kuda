Sqlite adapter of IndexStore — single file, zero server, rebuildable. Lives at .kuda/index.sqlite (gitignored).

§File format (blessed contract)

.kuda/index.sqlite is a plain sqlite3 database — the on-disk contract external readers may rely on. SqliteStore::open creates/upgrades it; SqliteStore::open_readonly is the auditor-safe open (no mkdir, no DDL, no file creation) that read-only consumers (e.g. mimus checkers) must use.

symbols(name TEXT, kind TEXT, file TEXT, line INTEGER, module TEXT)
edges(from_mod TEXT, to_mod TEXT, kind TEXT)
files(path TEXT PRIMARY KEY, hash TEXT, module TEXT)
meta(k TEXT PRIMARY KEY, v TEXT)   -- e.g. generated_at (unix secs)

kind spellings are [SymbolKind::as_str] / [EdgeKind::as_str] (kuda-core); unknown strings decode to Other/PackageDep fallbacks. Indexes are rebuildable — kuda sync regenerates them — so readers must tolerate a missing file and absent tables (SqliteStore::has_table).
