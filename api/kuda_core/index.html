kuda-core — domain types: cards, symbols, edges, provenance, and the kuda.toml config model. No ports, no integrations.

Memory tiers (ADR-0001): L0 RepoCard (always-load), L1 ModuleCard (on-demand), L2 Symbol/DepEdge graph (queried). Every card carries Provenance — staleness is a property of the data, not a promise in prose.

publish_order
Publish order for workspace members: every member’s path-deps on other members come first. Err on a dependency cycle. Used by scripts/release.sh.
